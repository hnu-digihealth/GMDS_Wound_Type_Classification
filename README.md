# Classifying Rare Wound Diseases using the AUCMEDI Framework
This repository contains the code and evaluation results for the GMDS 2025 abstract "Computational Dermatology – An Automatic System for Visually Classifying Rare Wound Diseases".

In this work the [AUCMEDI](https://github.com/frankkramer-lab/aucmedi) framework was used to create a first proof of concept regarding the automatic differentiation between four different kinds of wound images, the common common Venous Leg Ulcer (VLU) and the rare Livedo Vasculopathy (LV), Pyoderma Gangraenosum (PG), and Ulcus Hypertonicum Martorell (UHM).

While we sadly cant provide the data, this code should add some degree of reproducibility, highlighting the specific methods used to generate and evaluate the model for the classification task.

## Setup
The project was written for Python 3.11.
